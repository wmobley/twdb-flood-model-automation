# User guide

The repository is currently a scaffold.

## Finding the main pieces

- Start with `models/` for model inputs.
- Use `deconstructed-notebooks/` to inspect or document one processing step.
- Use `notebooks/` for reviewer-facing analysis.
- Use `load_balancer/` for reusable run-coordination code.
- Use `project/` for plans, presentations, meetings, decisions, and deliverables.

Do not commit credentials or restricted model archives. Record the approved external source in project metadata when a file cannot be stored in GitHub.
