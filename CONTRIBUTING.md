# Contributing

Keep changes focused on the current model, notebook, Deconstructed Notebook, or load-balancer work item.

Before opening a pull request:

1. Run `pytest`.
2. Describe any model or environment assumptions.
3. Do not include credentials, private model archives, or restricted project records.
4. Add or update project metadata when changing a presentation or deliverable.

Changes that affect project scope, contract deliverables, external integrations, or publication status should be recorded in `project/decisions/`.
