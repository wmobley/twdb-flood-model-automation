# Project records

This directory is the lightweight project-management and archive area for the contract.

- `plan.md` is the current roadmap and contract-task map.
- `meetings/` stores agendas, notes, and action items.
- `decisions/` stores dated approvals and design decisions.
- `presentations/` stores approved presentation sources and metadata.
- `deliverables/` stores draft and accepted outputs with metadata.
- `archive/` stores superseded project records or archive indexes.

Use dated filenames and keep a metadata file beside presentations and deliverables. Restricted source records should remain in the approved external system of record, with only a safe metadata pointer committed here.
